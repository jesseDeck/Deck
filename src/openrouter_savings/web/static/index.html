OpenRouter Savings & Downtime Calculator

Log what you actually pay providers directly, tell it which models to track, and it compares that spend against the cheapest OpenRouter-served provider for the same model. OpenRouter's public API only reports current pricing and uptime — this tool builds price/uptime history itself by polling going forward (via "Snapshot now" or the server's background poller). You can also backfill older prices from a CSV.

Backfill historical pricing (optional)

Paste CSV rows with header model,provider,prompt_price,completion_price,effective_date (USD per token, ISO date). Useful for prices from before you started tracking, e.g. exported from a pricing-history site such as BenchLM.ai.

Backfill historical downtime (optional)

Paste CSV rows with header model,provider,start,end (ISO datetimes, plus an optional notes column) for known outage windows. Useful for outages from before you started tracking, e.g. exported from an incident-monitoring site such as IsItDown.ai. Shown separately from polled uptime % below, since the two can overlap.
